# Supplementary research / 补充研究成果

These eight topical notes are an index and scope review of the original archived proofs, not newly peer-reviewed articles. The source notes, calculations, code and data are preserved under `research-history/`. The main classification manuscript is still the v0.1.0 research preprint. Earlier restricted results may be implied by it if the complete proof is correct, but their alternative constructions and finite certificates are retained for independent study. Do not infer that an early proof is correct just because a later candidate theorem subsumes its statement.
