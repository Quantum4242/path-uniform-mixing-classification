# Verification records

`release-rerun/` is the complete, actual run of the shipped eleven-script suite on Linux. `pdf-build.log` records the manuscript build. Other logs and reports are historical development evidence, including an unsuccessful q=33 exploratory estimate. Earlier LP-based certificates and exploratory scripts mentioned in historical reports have been superseded by the current proof and are not bundled here. The current verification suite does not depend on them.
