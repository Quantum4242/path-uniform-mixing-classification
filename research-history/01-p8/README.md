# P8 explicit readout (historical record)

The recovered original Chinese research note is [P8-quantum-walk.pdf](P8-quantum-walk.pdf). The separate [public P8 repository](https://github.com/wangjiashu1/P8-explicit-readout) contains the English proof, verification programs, protocol table and logs. Its README specifies 17 actual readout times on a half-integer grid, maximum 19.5, and strictly positive weights exceeding 0.027. The existence result and 17-point upper bound predate the explicit protocol; do not claim those as new.

The original replication ZIP and full repository tree could not be recovered into the container: library search recovered the PDF only, and the GitHub archive download was inaccessible. The public repository is linked rather than reconstructed. The recovered PDF has not been recompiled or reverified in this archival release.
