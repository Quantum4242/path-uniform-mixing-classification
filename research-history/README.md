# Research history — immutable source snapshots

This is a curated archive of the available original research packages, not a new set of peer-reviewed papers. Original ZIP members are extracted byte-for-byte, with only a common enclosing directory removed where present. Original claims, caveats, scripts, data and logs are retained, even where a later proof supersedes them. Some scripts retain original paths or optional numerical-search dependencies; use the current verification runner for the core result. Historical test logs are not new execution results. The no-author P19 release was selected instead of the alternate named release. No external literature is intentionally redistributed. See `SNAPSHOTS.json` for source-archive SHA-256 hashes, counts and provenance.
