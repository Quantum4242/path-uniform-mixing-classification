# Proposed licensing — maintainer confirmation required

The requested deliverable is a public, reusable research package. The proposed split is MIT for original verification/figure code and CC BY 4.0 for the original manuscript, figures and documentation. The MIT text is included in `LICENSE.code.proposed`; the documentation proposal refers to https://creativecommons.org/licenses/by/4.0/legalcode. These are **draft licensing choices**, not a declaration that any person has already executed a legal grant. No personal copyright holder is assigned. Before public upload, the maintainer must confirm authority to license the material, choose attribution and replace the proposed notice with the final license(s). For historical Lean files, confirm their provenance and existing licensing before redistribution. External literature remains under its own terms and is linked only. A public GitHub repository without an effective license is not automatically open source. Do not treat this candidate package as already licensed by the user.
